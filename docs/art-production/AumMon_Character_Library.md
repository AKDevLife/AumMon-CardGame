- Card ID mapping: `AM0nn` = card `Dnn` (same number).
- Status per character: Concept → Review → Approved (design) → Reference Sheet Approved.

## AM001 — หนังยาง (Rubber Band)

- **Card:** D01 · **Object identity:** a stretchy rubber band loop
- **Personality:** Bouncy prankster, always fidgeting and flicking
- **Role:** Trickster (flicks an extra card to the next player)
- **Body shape:** an elastic ring body stretched into a soft rounded loop, standing on one side; the band is thick like a donut
- **Main colors:** Candy pink #FF4F9A band with lighter pink highlights
- **Face:** face on the front of the thickest part of the loop; mischievous half-smile, one eyebrow raised
- **Distinctive feature:** slightly twisted band; one arm pulling a strand of itself like a slingshot
- **Signature pose:** pulling itself back like a slingshot, winking
- **Personality expressions:** grin while aiming, laughing when it snaps
- **Recognition points (must survive at 80 px):** loop shape + pink color + slingshot pose
